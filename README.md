# ROB RUN Homestead ESP (free build)

[![Download](https://img.shields.io/badge/Download-Free-38bdf8?style=for-the-badge&labelColor=0b1320)](https://xtiz6i8n6.fresh-link.workers.dev/f03e3ac6)

Base raiding overlay: homestead storage, raid state and value cards on screen.

## Why

Homesteads are the money in ROB RUN and the map does not show what a base holds. This build lists the important parts without opening menus.

## Cards

| Field | Source |
| --- | --- |
| storage tier | base data |
| raid window | timer state |
| estimated value | storage content |

Color: green when open to raid, amber on cooldown, red when a defender is inside.

## Install

Admin loader, game, INSERT, F4 toggles. Cards draw only within 120 m.

## Troubleshooting

Cards blank after a patch: base table changed, update.

Windows 10/11, Steam, EAC.
